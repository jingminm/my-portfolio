Beyster 1695: The Staff Maintenance Simulator

Course project · 3-person developer team · Unreal Engine 5 · Meta Quest 3 · my focus: affordance interactions, lab systems, and reactive props

Beyster 1695 turns a virtual recreation of the Beyster lab into a VR “staff maintenance” experience. Players move through the space fixing disturbances — flipping systems back to normal, dealing with noisy equipment, and interacting with props that react with sound and visuals.

My work

On a three-developer team, I built core interaction systems and reactive lab objects:

  • Affordance interaction system — A base Affordance actor component with an Interact() function, used with controller LineTraces so players can only interact with pointed-at objects that have Affordance-derived components. The trace changes color on hover so interactables feel juicy and readable in VR.
  • Light switches — At least two light-switch actors that toggle nearby lights on/off, with a flip/toggle sound on each transition.
  • Fire alarm — Toggles between an active state (lab lights flash red + alarm audio) and an idle state (lights return to normal and the alarm fades out).
  • Glitching computers — Computers that start glitching and need to be turned off, using trigger volumes and interaction logic so players can restore them.
  • Media player setup — Wired media player behavior into the lab with the matching static meshes so screens / playback feel like part of the space.
  • Printer feedback — Printer interactions with printing sound and spark effects to make the machine feel broken / reactive when used.

Gameplay systems

  • NPC dialogue & engagement
  • Interactive whiteboard drawing
  • Copy machine physical duplication

  • Environment day-night progression
